# 资料来源与数据说明

## 一、文字史料

1. 《广州沙面大街10号保护活化实录》，2024年。项目叙事锚点、沙面大街10号沿革、法租界14号地块及2019—2024年保护活化过程的主要依据。
2. 广州市情网（广州市地方志办公室）：沙面岛、沙面租界、沙面建筑群相关条目。
3. 《广州城市形态演进》：广州城市空间与沙面填筑、租界格局演变的背景参考。
4. 《羊城春秋：广州城市历史研究手记》：近代广州城市史与1915年乙卯水灾等背景参考。
5. 广州市文物考古研究院（gzwwxxw.gzkaogu.cn）不可移动文物介绍页：法国巡捕房、沙面展览馆、沙面南街12号等建筑的基础信息。
6. 广州市荔湾区不可移动文物名录；广州市文物局关于全国重点文物保护单位广州沙面建筑群之英国医院旧址装修事宜的复函。
7. 中文维基百科：东方汇理银行、广州十三行博物馆、群英会（俱乐部）、天祥洋行旧址、洛士利洋行旧址等条目，仅作交叉核对。

## 二、GIS 数据

- 建筑轮廓：OpenStreetMap，经 Overpass API 于 2026-11-12 提取，查询范围为沙面岛及周边（23.1068—23.1122 N，113.2350—113.2462 E），共 194 个建筑要素。
- 许可：© OpenStreetMap contributors，ODbL 1.0。
- 坐标系：WGS84。页面使用 Leaflet + 纯离线 OSM 底图，未混入 GCJ-02 坐标，不请求在线瓦片。
- 处理：按建筑名称、地址与候选池匹配；保留真实轮廓并做轻度抽稀；汇丰银行旧址因 OSM 无独立轮廓，改用门牌近似点定位，并在数据中标记 `geometry_precision: "point"`。
- 沙面岛示意边界：由岛内建筑轮廓凸包外扩生成，仅作辅助边界，**不是测绘岸线**。
- 离线底图：从 `tile.openstreetmap.de` 下载沙面及周边 z16—z19 的本地 OSM 瓦片（共 1511 张，`assets/tiles/`），页面用 `L.tileLayer` 直接读取，不请求在线瓦片。z19 覆盖岛屿核心区，z16—z18 另有一套南北加高的覆盖，保证竖屏容器也铺满。z19 的 29×19 瓦片另拼接为 4800 px 宽的 `assets/maps/shamian-osm-base.webp`，作为即时占位与瓦片缺失兜底。
- 瓦片覆盖边界：南西 `[23.079732,113.230591]`，北东 `[23.140360,113.251190]`（外圈 z16—z18）；z19 细节层为 `[23.103734,113.230591]` 至 `[23.115733,113.250504]`。默认视图紧致包含全部 23 个编号 POI；`minZoom` 为全部编号 POI 可见的级别，`maxBounds` 限制在瓦片覆盖范围内，瓦片铺满容器、无留边。
- 可选卫星底图：Esri World Imagery（`server.arcgisonline.com`），无需 API Key，需联网；署名 “Esri, Maxar, Earthstar Geographics”。卫星图层置于 2D 之上，离线时自动露出 2D 底图。

## 三、历史地图叠加（未启用）

- 曾核对 British Library《Map of Shameen, 1925》平面图；该图是示意图，不是测绘成果，无法做到测绘级精确配准。
- 按本轮要求，历史地图叠加功能及相关代码、控件、图片资源已移除。
- 故事线中的历史影像（赖阿芳照片、维多利亚酒店旧影等）为公有领域照片，不作为地理叠加底图。

- 全部照片来自 Wikimedia Commons，逐张保留作者、许可与文件页链接，详见 `data/credits.json` 与页面“资料来源”面板。

## 五、年代说明

- 所有建筑都有明确的显示年份；年代为约数时以“约”标注，不再显示“年代待核”标记。
- 沙面大街10号：书中序言称“49栋文物建筑”，部分官方资料按“54处”统计。本页不写死数量，仅在必要时并列说明。
- 台湾银行广州支行：资料记1907年设立，OSM 建筑 `start_date` 为1911，页面并列标注。
- 海关馆舍（东红楼）：资料记1909年竣工，OSM `start_date` 为1907，页面以1909为主并注明异说。
- 原美国领事馆：门牌有沙面大街56号与沙面三街2号两说，页面并列说明。
- 东方汇理银行：门牌有沙面一街3号与沙面南街16号两说，页面并列说明。
- 近似年代：
  - 旗昌洋行（19世纪末）：约1890。
  - 旧摩罗叉公寓（19世纪下半叶）：约1870。
  - 泰和洋行（OSM `start_date=1912`）：1912。
- 已补齐的可核年代：洛士利洋行1906、英国医院&招商局旧址1932、广东外事俱乐部1865、沙面展览馆/天祥洋行1924。
